# LLD — Case Studies

Low-Level Design deep-dives for classic systems. Each sub-folder mirrors a case study from `hld/case-studies/` and contains class diagrams, interface definitions, and working code organised by language.

## Structure per Case Study

```
lld/case-studies/<system-name>/
├── README.md          ← class diagram, key interfaces, design decisions
├── java/
├── python/
├── go/
└── typescript/
```
