# High-Level Design

This folder contains all High-Level Design (HLD) content. Everything here is language-agnostic — architecture diagrams, component breakdowns, trade-off discussions, and interview angles.

## Sub-folders

| Folder | What goes here |
|---|---|
| `fundamentals/` | Core HLD concepts: scaling, caching, load balancing, databases, queues |
| `case-studies/` | HLD architecture for classic systems (URL shortener, chat system, etc.) |

## Content Template

Every file in this folder must follow the structure below:

```
## Problem Statement
## Requirements
### Functional Requirements
### Non-Functional Requirements
## Architecture Diagram
## Component Breakdown
## Trade-offs
## Interview Angle
```
