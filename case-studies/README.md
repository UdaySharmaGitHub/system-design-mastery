# Case Studies

End-to-end system design walkthroughs. Each case study folder ties together the HLD and LLD layers in one place.

## Structure per Case Study

```
case-studies/<system-name>/
├── README.md          ← overview, requirements, links to HLD and LLD
├── hld.md             ← or link to hld/case-studies/<system>/
└── lld.md             ← or link to lld/case-studies/<system>/
```

For large case studies, the HLD and LLD live in their respective top-level folders and are linked from here. For smaller or self-contained ones, both can live directly in this folder.
